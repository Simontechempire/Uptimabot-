🚀 Simon Tech Monitor

Simon Tech Monitor is a simple website monitoring system that checks websites and displays their current status.

✨ Features

- 🟢 Check if a website is online
- 🔴 Detect when a website is down
- ⚡ Monitor response time
- 📊 View uptime statistics
- 📈 Track monitoring history
- 🔔 Send alerts when a website goes down
- 📱 Mobile-friendly dashboard

🛠️ Technologies

- HTML
- CSS
- JavaScript
- Netlify

🎯 Goal

The goal of Simon Tech Monitor is to provide a simple and easy-to-use tool for monitoring website availability and performance.
